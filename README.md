# PlacementPro – Job & Placement Management Dashboard

PlacementPro is a React-based job and placement management dashboard designed to help students manage their placement journey in one place.

## Features

### 📊 Dashboard

- View total job applications
- Track interview count
- Track selected applications
- Track rejected applications
- Dynamic statistics based on application data

### 💼 Applications

- Add new job applications
- Edit existing applications
- Delete applications
- Search applications by company
- Filter applications by status
- Store application data using LocalStorage

### 📅 Interviews

- Add upcoming interviews
- Store company name
- Select interview round
- Add interview date
- Add preparation notes
- Store interview data using LocalStorage

### 📚 Preparation

- Track preparation progress
- DSA
- DBMS
- Operating Systems
- Computer Networks
- Aptitude
- React
- Update progress using the +10% button
- Save progress using LocalStorage

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- LocalStorage
